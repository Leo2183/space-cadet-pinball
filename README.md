# 三维弹球: 太空军校生(现代化重制版)

对经典 Windows 游戏《3D Pinball - Space Cadet》的致敬复刻。玩法机制参照原作
(任务晋升军衔、奖章降落靶、超空间滑道、虫洞、任务燃料等),代码、美术贴图与
音效均为本项目原创实现,不包含原版游戏的任何受版权保护素材。

技术栈:**Python + Ursina(Panda3D) 渲染 + 自研 2D 弹球物理引擎**。视角为纯 2D
俯视正交投影(同原版观感),3D 渲染管线保留了光照与阴影质感。

## 运行

**推荐:双击启动器**

| 文件 | 说明 |
| --- | --- |
| `launcher.pyw` | 图形启动器:显示环境状态/最高分,一键开始游戏、运行自检、安装依赖(仅标准库,双击无黑窗) |
| `启动游戏.bat` | 批处理兜底:自动定位 Python,缺依赖时自动安装,异常退出时暂停显示报错 |

也可以手动运行:

```bash
pip install -r requirements.txt
python main.py
```

- 依赖:Python 3.10+、Ursina 8.x、Pillow
- 启动器命令行模式:`python launcher.pyw --check`(检查环境)、`--launch`(直接开玩)
- 首次启动会自动从系统字体目录拷贝一份中文字体到项目目录(用于 HUD 中文显示)
- 自动冒烟测试(自动发射、随机拍弹板、截图后退出):`python main.py --smoke`
- 想放桌面:右键 `launcher.pyw` → 发送到 → 桌面快捷方式

## 操作

| 按键 | 功能 |
| --- | --- |
| `Z` 或 `←` | 左弹板 |
| `/` 或 `→` | 右弹板 |
| `空格` 或 `↓` 按住 | 发射杆蓄力,松开发射(蓄力越久射得越远) |
| `X` / `.` / `↑` | 推台(左/右/上)。连续推台会触发 TILT,弹板失效直至丢球 |
| `F1` | 帮助 |
| `F2` | 新游戏 |
| `P` | 暂停 |
| `Esc` | 退出 |

## 玩法(与原版机制的对应)

- **任务系统**:击中场中任务靶开启任务(共 8 种,随军衔解锁),任务有燃料
  (倒计时)限制,绿色虫洞可补燃料。多球期间任务进度冻结(原版规则)。
- **军衔**:完成任务数决定晋升——军校生 → 少尉 → 中尉 → 上尉 → 少校 →
  中校 → 上校 → 准将 → 舰队上将。每次晋升奖励分数和一个备用球。
- **攻击缓冲器**(×3):撞击得分,任务"攻击训练"的目标。
- **奖章降落靶**(×3):击落整组点亮奖章灯(蓝→红→紫)并提升全场倍率
  (×1→×2→×3→×5);紫灯状态下再集齐一组 = 救球。
- **超空间滑道**(右侧,左弹板击打):5 级奖励灯——加分、加分、升起中央
  立柱、点亮出球道救援、多球!之后清零重积。
- **虫洞**:黄色(左上)/绿色(中下)互相传送;黄灯状态下进黄色虫洞可救球。
- **发射坡道**(左侧单向轨道):从台顶回绕计"发射训练"进度。
- **再入航道**:两侧内道滚灯。
- **出球道救援**:超空间第 4 级点亮后,球落入两侧出球道会被弹回内道。

```
launcher.pyw           图形启动器(双击运行, 仅标准库)
启动游戏.bat            批处理启动器(自动装依赖, 兜底用)
main.py                入口: Ursina 渲染、输入、HUD、冒烟测试
spacecadet/
  config.py             全部可调参数(重力、球速、弹板、计分……)
  physics.py            纯 Python 2D 物理引擎(墙/弹板/缓冲器/虫洞/单向门)
  table.py              球台几何定义(仿原版布局)
  rules.py              计分/任务/军衔/多球/倾台状态机
tests/test_physics.py   无头自动化测试(物理+规则, 17 个用例)
```

## 已知简化(相对原版)

- 任务为 8 种代表性设计(原版 17 种),奖励数值为自定平衡值;
- 视觉为现代化重制(纯 2D 俯视、星空台面、霓虹光边、阴影),非原版贴图还原;
- 无音效(按需求省略)。

## 环境备注(开发时踩坑记录)

所用 Ursina 8.3.0 存在几个坑,代码中已规避:

1. `Entity.color`(colorScale 通道)对所有着色器不生效——实体着色统一使用
   1×1 纯色贴图(`tex_color()`);
2. `Mesh` 实体(如程序化 `Cylinder`)继承 `NodePath`,共享同一实例会被最后
   一个使用者 `reparent` 抢走——每个实体必须独立实例化;
3. 内置模型没有 `sphere`/`cylinder`,需用 `icosphere` 与
   `ursina.models.procedural.cylinder.Cylinder`;
4. 截图用相对路径 `base.win.saveScreenshot(name)`(绝对路径会静默失败);
5. `Vec3(x, y)` 两参构造语义异常(得到 `(x, x, y)`), 构造向量必须传满三个分量;
6. `Text` 的颜色通道失效(恒白), 文字上色需用 PIL 渲染贴图(HUD 的 Label 方案);
   带透明通道的贴图会进透明渲染队列、被 3D 场景盖住, 文字贴图用不透明深色底。
